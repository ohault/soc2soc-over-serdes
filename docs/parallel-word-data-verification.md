# Parallel-word DATA transmitter verification

The experimental `bonded_wire_tx_lane_parallel` now has two independent
regressions:

- A 32-bit single-beat golden-vector test that holds the first output word
  under backpressure and checks output stability.
- A multi-beat test that constructs the expected v0 frame independently,
  including header CRC-16 and frame CRC-32C, then compares every emitted byte.

The multi-beat test is parameterized and the CI workflow elaborates/runs it at
8, 16 and 32 bits. It sends a seven-byte payload, which exercises full and
partial final input words at all three widths, and varies output READY to
exercise stalls while the frame is being emitted.

The transmitter latches the packet length at admission and checks the
cumulative payload byte count before accepting the final beat. The byte-serial
transmitter remains the protocol reference; the new tests currently use an
independently generated byte stream rather than replacing or modifying that
reference.
